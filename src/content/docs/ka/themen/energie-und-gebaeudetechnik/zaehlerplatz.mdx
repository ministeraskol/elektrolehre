Zählerplatz (მრიცხველის ადგილი) არის Netzbetreiber (ქსელის ოპერატორი)-თან დამაკავშირებელი წერტილი. **§ 13 NAV**-ის თანახმად, აქ მუშაობა შეუძლია მხოლოდ იმ კომპანიას, რომელიც შეტანილია **Installateurverzeichnis** (ინსტალატორთა რეესტრი)-ში. როგორც Azubi (შეგირდი), შენ ზედამხედველობის ქვეშ აწყობ Zählerschrank (მრიცხველის კარადა)-ს – რეგისტრაცია, ექსპლუატაციაში გაშვება და დალუქვა ხორციელდება კომპანიისა და Netzbetreiber-ის მიერ. Hausanschlusskasten (სახლის შემაერთებელი ყუთი)-ის წინ ყველაფერი Netzbetreiber-ის საკუთრებაა; იქ მათ გარეშე არასდროს მუშაობენ.
:::

## რა არის Zählerplatz?

Zählerplatz არის ადგილი, სადაც Energie (ენერგია) ქსელიდან გადადის მომხმარებლის დანადგარში და ხდება მისი **გაზომვა**. ის განთავსებულია Zählerschrank-ში (სახლის შემაერთებელი ოთახი, სარდაფი, დერეფანი) და შედგება რამდენიმე სექციისა და სივრცისგან, რომლებსაც **VDE-AR-N 4100** (ტექნიკური წესები დაბალი ძაბვის ქსელისთვის, მოკლედ TAR) ზუსტად განსაზღვრავს. Netzbetreiber-ები მათ ავსებენ თავიანთი **Technischen Anschlussbedingungen (TAB)** (ტექნიკური შეერთების პირობები)-ით, რომელზეც § 14 NAV მიუთითებს.

ყველაფერი, რაც აქ წერია, ეხება **ახალ** Zählerplatz-ებს. არსებული დანადგარების დატოვება ნებადართულია მანამ, სანამ მათში არსებითი ცვლილებები არ შევა.

## დენის გზა

<ZaehlerplatzSchema />

<Steps>

1. **Hausanschlusskasten (HAK).** აქ მთავრდება Netzbetreiber-ის ქსელის კაბელი. HAK-ში განთავსებულია **NH-Sicherungen** (დამცველები, მაგალითად 3×63 A). HAK არის **დალუქული**; NH-Sicherungen-ის ამოღება Netzbetreiber-ის საქმეა ან მხოლოდ შეთანხმებით ხდება.

2. **Hauptleitung (მთავარი ხაზი).** HAK-დან Zählerschrank-ამდე, **გაზომვის გარეშე**. Querschnitt (განივკვეთი) Leistung (სიმძლავრე)-ის მიხედვით, ძირითადად NYY-J ან NYM-J **5×16 mm²** ან მეტი. ის უნდა იყოს **მოკლე ჩართვის მიმართ მდგრადი** და გაყვანილი განშტოებების გარეშე; Hauptleitung არ უნდა გადიოდეს სხვა ბინებში.

3. **Unterer Anschlussraum (ქვედა შეერთების სივრცე).** Zählerschrank-ში Hauptleitung მოდის **Hauptleitungsabzweigklemme** (მთავარი ხაზის განშტოების კლემები)-ზე ან **Sammelschiene** (საკრებულო ზოლი)-ზე. იქიდან იკვებება თითოეული Zählerfeld (მრიცხველის ველი). აქ ასევე ხდება მიერთება **Haupterdungsschiene (HES)** (მთავარი დამიწების ზოლი)-თან და PEN-ის დაყოფა PE-დ და N-ად (TN-C-S).

4. **SLS-Schalter (სელექციური მთავარი ავტომატური ამომრთველი).** თითოეული Zähler (მრიცხველი)-ის წინ დგას **SLS-Schalter** (მაგალითად 3×35 A, E-მახასიათებელი). ეს არის ბინის Vorsicherung (წინასწარი დამცველი) და **Freischalten** (ძაბვის მოხსნა)-ის წერტილი ელექტროტექნიკური სამუშაოებისთვის. HAK-ისგან განსხვავებით, მისი მართვა შესაძლებელია Netzbetreiber-ის გარეშე.

5. **Zählerfeld.** Zähler მაგრდება Zählerplatz-ზე: დღეს ძირითადად როგორც **eHZ** (ელექტრონული საყოფაცხოვრებო მრიცხველი, ჩასამაგრებელი ტექნოლოგია) ან **Drei-Punkt-Befestigung** (სამწერტილიანი სამაგრი)-ზე (BKE-I-ადაპტერი). Zähler ეკუთვნის **Messstellenbetreiber** (გაზომვის წერტილის ოპერატორი)-ს, ის აყენებს და **ლუქავს** მას. ელექტროტექნიკური კომპანია აწვდის მზა, შემოწმებულ გაყვანილობას Zähler-ის კლემებამდე.

6. **Oberer Anschlussraum / Verteilerfeld (ზედა შეერთების სივრცე / გამანაწილებელი ველი).** Zähler-ის შემდეგ იწყება მომხმარებლის დანადგარი: Hauptschalter (მთავარი ამომრთველი), საჭიროების შემთხვევაში SPD ტიპი 1/2, RCD-ები და LS-Schalter (ხაზის დამცავი ავტომატური ამომრთველი) – ან მხოლოდ გამოსავალი ბინის [Unterverteilung (ქვეგამანაწილებელი ფარი)](../unterverteilung/)-ისკენ.

7. **Raum für Zusatzanwendungen (RfZ) და APZ.** VDE-AR-N 4100 მოითხოვს ადგილს **Smart-Meter-Gateway**-ისთვის, მართვის ბლოკისთვის და საკომუნიკაციო ტექნიკისთვის (**APZ** – ჩასაკეტი ადგილი დამატებითი აპლიკაციებისთვის, მინიმუმ 300 მმ სიმაღლის, საკუთარი 230-V-იანი წრედით). ამ სივრცეების გარეშე Netzbetreiber არ მიიღებს Zählerplatz-ს.

</Steps>

## მოთხოვნები Zählerschrank-ის მიმართ

| პუნქტი | მოთხოვნა (VDE-AR-N 4100, TAB) |
|---|---|
| **კარადა** | შემოწმებული Zählerschrank DIN VDE 0603 / DIN 43870-ის მიხედვით, Schutzart (დაცვის ხარისხი) მინიმუმ IP31 (სარდაფში ხშირად IP44), Schutzklasse (დაცვის კლასი) II |
| **სიმაღლე** | Zähler-ის ცენტრი იატაკიდან 0,8 მ-დან 1,8 მ-მდე |
| **წვდომა** | თავისუფალი წვდომა, 1,2 მ თავისუფალი სივრცე კარადასთან, არა აბაზანაში, ტუალეტში ან ნესტიან ოთახებში |
| **განათება** | Zählerplatz უნდა იყოს წაკითხვადი – Steckdose (შტეფსელი) და განათება სახლის შემაერთებელ ოთახში |
| **მარკირება** | თითოეული Zählerfeld ბინის / მომხმარებლის მიხედვით წარწერით, მუდმივი |
| **Freischaltung** | SLS თითოეული Zähler-ის წინ, ყველა პოლუსის გათიშვის შესაძლებლობით |
| **Überspannungsschutz** (გადაძაბვისგან დაცვა) | SPD ტიპი 1 ან ტიპი 1/2 Zählerschrank-ში ახალ შენობებში (DIN VDE 0100-443/-534), ადგილი გათვალისწინებული უნდა იყოს |
| **სათადარიგო დენი / PV** | დამატებითი ველები გენერატორული დანადგარებისთვის და აკუმულატორებისთვის საკუთარი გაზომვით VDE-AR-N 4105-ის მიხედვით |

## პროცესი კომპანიაში

<Steps>

1. **რეგისტრაცია Netzbetreiber-თან.** მუშაობის დაწყებამდე კომპანია აცხადებს შეერთებას ან ცვლილებას (ქსელის შეერთების პორტალი). Netzbetreiber გასცემს ნებართვას შეერთების სიმძლავრეზე, Zähler-ის ტიპზე და ვადებზე.

2. **დაგეგმვა.** Zählerfeld-ების რაოდენობა (თითო ბინისთვის, პლუს საერთო დენი, სითბური ტუმბო, Wallbox), Hauptleitung-ის Querschnitt, კარადას პოზიცია, APZ და RfZ.

3. **Fünf Sicherheitsregeln (ხუთი უსაფრთხოების წესი).** რეკონსტრუქციისას: Freischalten HAK-ში მხოლოდ Netzbetreiber-თან ერთად. ახალ შენობაში: Hauptleitung ჯერ არ არის შეერთებული.

4. **კარადის მონტაჟი და Hauptleitung-ის შეერთება.** ძარღვები Aderendhülsen (ძარღვის ბოლოების ჰილზები)-ით ან მწარმოებლის მითითების მიხედვით, Drehmoment (ბრუნვის მომენტი) გათვალისწინებით, PEN PEN-ზოლზე, დაყოფა PE-დ და N-ად.

5. **ველების აღჭურვა.** SLS, Zählerplatz კლემებით, გამოსავალი Unterverteilung-ისკენ, APZ-წრე, მარკირება.

6. **შემოწმება.** Erstprüfung (პირველადი შემოწმება) DIN VDE 0100-600-ის მიხედვით: PE-ს გამტარობა, Isolationswiderstand (იზოლაციის წინაღობა), Drehfeld (ბრუნვის ველი) (მარჯვენა ბრუნვის ველი Zähler-ზე!), ოქმი.

7. **დასრულების შესახებ შეტყობინება.** კომპანია აცხადებს დანადგარის მზადყოფნას Inbetriebsetzungsprotokoll (ექსპლუატაციაში გაშვების ოქმი)-ით და პასუხისმგებელი Elektrofachkraft (ელექტროტექნიკური სპეციალისტი)-ის ხელმოწერით. Netzbetreiber ან Messstellenbetreiber აყენებს Zähler-ს, ლუქავს და რთავს დენს.

</Steps>

## ხშირი შეცდომები

- **Drehfeld არასწორია.** Zähler-ზე უნდა იყოს **მარჯვენა ბრუნვის ველი** (L1–L2–L3). Netzbetreiber ამოწმებს ამას ექსპლუატაციაში გაშვებისას; არასწორი Drehfeld ნიშნავს: დენის ჩართვა არ ხდება.
- **არ არის APZ / RfZ.** ახალ შენობებში მიღებაზე უარის თქმის ყველაზე ხშირი მიზეზი.
- **Hauptleitung ძალიან პატარაა ან აქვს განშტოება.** უნდა გაუძლოს NH-Sicherungen-ის Nennstrom (ნომინალური დენი)-ს.
- **PEN არ არის სწორად დაყოფილი** – PE და N დაყოფის შემდეგ კვლავ შეერთებულია.
- **Zähler არ არის წაკითხვადი** (ძალიან მაღლა, დაფარული, კარების უკან).
- **ლუქი გატეხილია.** „მხოლოდ ცოტა ხნით“ მანიპულაციაც კი – ისჯება როგორც დენის ქურდობა.
